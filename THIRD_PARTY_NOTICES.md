# Avisos de terceiros

## USBip-win2

A versão 1.1 inclui o instalador oficial **USBip-win2 0.9.8.0 x64**, intacto, do projeto [usbip-win2](https://github.com/vadimgrn/usbip-win2/releases/tag/v.0.9.8.0). Ele instala o cliente, drivers UDE/filtro e a dependência Visual C++ do pacote original. A licença BSD de 2 cláusulas acompanha o aplicativo em `USBip-LICENSE.txt`; dependências incorporadas mantêm seus próprios termos e avisos no pacote oficial. SHA-256: `81f426741f7ee2ed991febe24a22daca8400b6ae2f171054e3fb404897e15d39`. O USBip permanece um produto separado no Windows; desinstalar a ponte não o remove.

## Microsoft .NET

Os binários self-contained incluem componentes do Microsoft .NET 8 sob suas respectivas licenças. O pacote de release acompanha `DOTNET-LICENSE.txt` e `DOTNET-ThirdPartyNotices.txt`, obtidos do runtime usado para o build.

## Tomlyn

O assistente usa [Tomlyn 0.19.0](https://github.com/xoofx/Tomlyn/tree/0.19.0) para validar TOML antes de acrescentar configurações. Sua licença BSD de 2 cláusulas acompanha o aplicativo em `TOMLYN-LICENSE.txt`.

## Inno Setup

Inno Setup é usado apenas como ferramenta de compilação do instalador; seu compilador não é redistribuído dentro do produto. Consulte [jrsoftware.org](https://jrsoftware.org/isinfo.php) para termos e downloads oficiais.

## Marcas e serviços

OpenAI Codex, Pioneer DJ, AlphaTheta, Windows e demais nomes são marcas de seus respectivos titulares. A menção identifica compatibilidade e não implica endosso.
