# Avisos de terceiros

## USBip-win2

A ponte usa, quando instalado separadamente pelo usuário, o cliente e o driver UDE do projeto [usbip-win2](https://github.com/vadimgrn/usbip-win2). A partir da série 0.9.7.0 o projeto declara licença BSD de 2 cláusulas. Nenhum binário, driver ou instalador USBip é incorporado à versão 1.0 desta ponte.

## Microsoft .NET

Os binários self-contained incluem componentes do Microsoft .NET 8 sob suas respectivas licenças. O pacote de release acompanha `DOTNET-LICENSE.txt` e `DOTNET-ThirdPartyNotices.txt`, obtidos do runtime usado para o build.

## Inno Setup

Inno Setup é usado apenas como ferramenta de compilação do instalador; seu compilador não é redistribuído dentro do produto. Consulte [jrsoftware.org](https://jrsoftware.org/isinfo.php) para termos e downloads oficiais.

## Marcas e serviços

OpenAI Codex, Pioneer DJ, AlphaTheta, Windows e demais nomes são marcas de seus respectivos titulares. A menção identifica compatibilidade e não implica endosso.
